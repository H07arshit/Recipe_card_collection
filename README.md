# 🍳 Recipe Card Collection

> A beginner-friendly web project that displays favorite recipes as styled cards with images, ingredients, preparation steps, and nutritional info.

**Group 6 · Project #11 · Semester 1**

---

## 📖 Description

Recipe Card Collection is a collection of recipe cards showing ingredients and preparation steps for favorite dishes. Each card has an image, a short description, an ingredient list, numbered steps, and a nutrition table, laid out in a responsive card grid with a hover effect.

Built with **HTML and CSS**. No frameworks or libraries.

---

## ✨ Features

| Feature | Description |
|---|---|
| 🃏 **Recipe Cards** | Cards for Burger, Coffee, Momos, Noodles, Pancakes, and Pizza, each with an image, title, and description |
| 📋 **Ingredients List** | Unordered list (`<ul>`) with the quantity for each ingredient |
| 🔢 **Preparation Steps** | Ordered list (`<ol>`) with step-by-step instructions |
| 📊 **Nutrition Table** | Calories, protein, carbs, and fat for each recipe |
| 🎨 **Hover Effect** | Cards react when you hover over them |
| 📱 **Responsive Layout** | Card grid built with Flexbox/Grid |

---

## 🛠️ Technologies Used

- **HTML5**: semantic structure, `<ul>` for ingredients, `<ol>` for steps, `<table>` for nutrition
- **CSS3**: Flexbox/Grid card layout, styled lists, hover effects, transitions

## 🚀 Getting Started

1. **Download or clone** the project folder.
   ```bash
   git clone <your-repository-url>
   cd Recipe_card_collection
   ```
2. **Open `index.html`** in any modern browser (Chrome, Firefox, Edge, Safari).
3. That's it. No installation or build step needed.

---

## 🎮 How to Use

1. **Browse** the recipe cards on the main page.
2. **Hover** over a card to see the hover effect.
3. **Read** the ingredients and follow the numbered steps.
4. **Check the nutrition table** for each recipe's nutritional values.
